# مستشفى الديوانية التعليمي — الموقع الإلكتروني الرسمي

موقع ثابت (Static) عربي RTL متجاوب، جاهز للنشر على GitHub Pages على النطاق:
https://diwaniyahhospital.org/

## قبل النشر — تحقق من البيانات الرسمية
البيانات التالية موجودة في الموقع ويجب أن تكون معتمدة من إدارة المستشفى:
- البريد: media@diwaniyahhospital.org (يجب إنشاء هذا البريد فعليًا على النطاق)
- الهاتف: +964 773 340 7285
- العنوان: الديوانية - مجسر أبو الفضل

لتعديلها: ابحث عنها واستبدلها في ملفات HTML (تظهر في الترويسة والتذييل وصفحة التواصل وبيانات JSON-LD في index.html).

## إضافة المحتوى
كل المحتوى المتغير في `assets/js/site.js`:
- `news` الأخبار
- `announcements` الإعلانات
- `services` الخدمات
- `departments` الأقسام

القوائم فارغة عمدًا؛ تظهر رسالة «سيتم النشر بعد الاعتماد» حتى تضاف بيانات رسمية.
لا تُضف معلومات عن أطباء أو أقسام أو خدمات قبل اعتمادها.

## النشر على GitHub Pages
1. أنشئ Repository جديدًا وارفع الملفات إلى فرع `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. سيعمل `.github/workflows/deploy.yml` تلقائيًا مع كل Push.
4. Settings → Pages → Custom domain: اكتب `diwaniyahhospital.org` واحفظ
   (عند النشر عبر Actions يجب ضبط النطاق من الإعدادات؛ ملف CNAME وحده لا يكفي).
5. بعد نجاح فحص DNS فعّل **Enforce HTTPS**.

## إعدادات DNS (لدى Hostinger)
احذف سجلات A الحالية الخاصة بصفحة الـ Parking ثم أضف:

| النوع | الاسم | القيمة |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| AAAA | @ | 2606:50c0:8000::153 |
| AAAA | @ | 2606:50c0:8001::153 |
| AAAA | @ | 2606:50c0:8002::153 |
| AAAA | @ | 2606:50c0:8003::153 |
| CNAME | www | <اسم-الحساب>.github.io |

لا تحذف سجلات MX إذا كان البريد مفعّلًا على النطاق.
يُستحسن أيضًا توثيق النطاق في GitHub (Settings → Pages → Verified domains) لحمايته من الاستيلاء.

## التشغيل محليًا
```
python3 -m http.server 8000
```
ثم افتح http://localhost:8000 (المسارات مطلقة `/assets/...` لذا يلزم خادم محلي بدل فتح الملف مباشرة).
